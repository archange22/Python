# Académique

Académique est une application web installable consacrée à trois parcours : Python, intelligence artificielle et développement Discord.

## Fonctionnalités

- Accueil avec accès direct aux trois formations.
- Catalogue des cours et programme de chaque formation.
- Lecture des cours dans l'application.
- Suivi local des cours terminés.
- Installation depuis la page « À propos » lorsqu'on consulte le site dans un navigateur compatible.
- Contact direct : archangekouaho@gmail.com.
- Cache hors connexion pour l'interface et les documents déjà chargés.

## Installation

Sur le site GitHub Pages, ouvre « À propos » puis « Installer Académique ». Selon le navigateur et l'appareil, l'installation est proposée directement ou expliquée étape par étape.

Cette version est une PWA (application web progressive). Elle ne fournit pas encore de fichier APK indépendant. Une publication Android sur Google Play nécessitera une étape de packaging, de signature et de vérification des exigences Google.

## Parcours pédagogiques

- Python
- Intelligence artificielle
- Développement Discord

Les cours contiennent ou devront contenir les explications, exemples, exercices et corrections dans le même document. Les documents Python non encore disponibles restent indiqués comme à préparer.

## Données

La progression des cours terminés est conservée localement dans le navigateur. Cette version ne demande pas de compte et ne synchronise pas la progression entre plusieurs appareils.
