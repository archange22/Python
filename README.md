# Python Facile 🐍

Application gratuite pour apprendre Python en français, pensée pour les débutants et les écrans mobiles.

## Fonctionnalités
- 8 leçons progressives avec exemples de code.
- Exercices pratiques et tests à effectuer.
- Indices masqués pour essayer avant de regarder.
- 3 projets guidés : jeu de devinette, calculatrice et quiz.
- Recherche et filtre par niveau.
- Progression enregistrée localement sur l'appareil.
- Application web installable (PWA) et mode hors ligne après le premier chargement.

## Utilisation
Ouvre l'application dans un navigateur. Sur Android, ajoute-la à l'écran d'accueil depuis le menu du navigateur. Pour exécuter les exercices Python, utilise Pydroid 3.

## Publication GitHub Pages
1. Ouvre **Settings → Pages**.
2. Dans **Build and deployment**, choisis **Deploy from a branch**.
3. Sélectionne **main** et le dossier **/ (root)**, puis enregistre.
4. L'application sera publiée à l'adresse `https://archange22.github.io/Python/` après la fin du déploiement.

Aucun compte, aucune clé API et aucun serveur backend ne sont nécessaires.
